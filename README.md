# Intern Performance Evaluation Metrics

## Project Overview

This project evaluates and tracks intern performance using a metrics-based system.

The project uses Python and Pandas to calculate key performance indicators and generate a monthly supervisor report.

## Objectives

- Evaluate intern performance using measurable KPIs
- Calculate task completion rates
- Measure project quality
- Analyze mentor feedback
- Track attendance
- Calculate overall performance scores
- Generate performance ratings
- Create department-level performance analysis
- Prepare a monthly supervisor report

## KPIs

The following KPIs were used:

- Task Completion Rate
- Average Task Completion Time
- Project Quality
- Mentor Feedback
- Attendance
- Overall Performance Score
- Performance Rating

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Microsoft Excel
- GitHub

## Key Analysis

The project provides:

- Overall internship performance
- Department-level comparison

- Mentor feedback analysis
